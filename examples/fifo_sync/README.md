# Parameterized Synchronous FIFO

This directory contains a parameterized synchronous FIFO developed for the AI-Driven RTL Design and Verification Assistant project.

Current status:

- Specification completed
- RTL implementation
- Self-checking testbench
- Verilator lint
- Waveform generation

The FIFO will later become one of the benchmark designs used to evaluate AI-generated RTL and automatic RTL repair.
